# 1836.15 數律終極量化系統 (React + TypeScript 重構版)

基於 1836.15 質能數律中樞與 142857 走馬燈時空雙重共振鎖的智能量化系統。全面重構為 React + TypeScript + Vite 架構，整合雙核 AI 推理（本地粵語快算大腦 + 雲端 Claude / Gemini 深度推演），提供專業美股與港股即時行情、回測回放與時空反轉共振信號。

## 🚀 快速啟動

```bash
# 1. 安裝依賴
npm install

# 2. 啟動開發伺服器 (包含 Vite SPA + 後端行情/AI/新聞代理)
npm run dev

# 3. 生產環境建置與啟動
npm run build
npm start
```

伺服器運行於 `http://0.0.0.0:3000`。

## ✨ 核心量化架構

### 1. 1836.15 質能數律中樞模型
- **歸元原理**：數字根模 9 運算，捕捉 3、6、9 核心共振點位。
- **動態樞紐**：自動計算動態強支撐、弱支撐與動態阻力線。
- **神準高低位**：神奇九轉風格標註極值點位。

### 2. 142857 時空雙重共振鎖 (`calculateCosmicReversalSignal`)
- **徹底過濾垂直斷裂線**：嚴密過濾末端空值、0 或初始預設佔位棒線（如 1836.15、0.08），杜絕圖表斷崖線。
- **引力容錯窗口 (±1.5%)**：以近一年歷史極值為 Day 0 錨點，針對 14.28%、18.36%、28.57%、36.72%、57.14% 等引力階梯設定 ±1.5% 容錯窗。
- **時空週期共振**：結合 `[14, 28, 57, 142, 285, 571]` 週期窗（±1 天容錯），精準觸發 `STRONG_BUY` 與 `CRITICAL_SELL`，慢速震盪鎖定為 `STATUS: HOLD`。

### 3. 傅立葉 Z 軸與全息預測 (Fourier Z-Axis)
- **收益率 FFT + 漢寧窗**：提取市場能量最強 Top 5 循環週期。
- **三源融合方向**：結合趨勢斜率、技術指標評分（RSI、MACD、布林 %B、ATR）與頻譜偏壓，預測未來 5 日方向概率（▲ 看多 / ▼ 看空 / — 震盪）。
- **彩帶狀態**：EMA 10/20/50 多空帶動態展示能量強度。
- **全息預測線**：以現價為中樞進行加法波動投影。

### 4. 雙核 AI 大腦
- **本地 AI 大腦**：秒級響應，純正香港粵語口語，回答個股支撐阻力、進出場位與回測評級。
- **專家深度推演**：支持本地配置 Claude、自建 Gemini 或自定義 OpenAI 相容 API，自動注入 15 維度真實市場數據上下文。
