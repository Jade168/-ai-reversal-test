# 1836.15 數律量化分析系統 V2.0 Ultimate

基於數律模型的智能量化分析系統,整合Claude/Gemini雙AI引擎,提供專業的港股美股分析

## 🚀 快速開始

### 運行方法
```bash
# 1. 安裝依賴
pip install -r requirements.txt

# 2. 啟動服務
python server.py

# 3. 打開瀏覽器訪問
http://127.0.0.1:1836
```

## 🎯 核心特色

### 1836.15數律模型
- 基於數學歸元原理的量化模型
- 識別3、6、9共振點位
- 動態計算支撐阻力位
- 歷史回測驗證有效性

### 雙AI驅動
- **本地AI**: 基於規則的快速分析
- **Claude/Gemini**: 深度學習的專業建議
- 量化操作建議(入場/止盈/止損)
- 風險等級評估

### 全球市場覆蓋
- 美股: NASDAQ, NYSE
- 港股: HKEX
- A股: SSE, SZSE
- 外匯、加密貨幣

## 🔧 技術架構

- **後端**: Python + Flask
- **前端**: 原生JavaScript + Chart.js
- **AI**: Claude API / Gemini / 本地算法
- **數據源**: 東方財富API + AKQuant API
- **部署**: 輕量級單機部署

## 📊 使用流程

1. **配置AI API** (選擇Claude/Gemini/自定義)
2. **初始化AI** (點擊初始化按鈕)
3. **刷新熱點** (獲取最新全球財經新聞)
4. **輸入代碼** (TSLA/00700/NVDA等)
5. **啟動分析** (查看K線圖和回測數據)
6. **回放回測** (觀看歷史信號生成過程)
7. **專家分析** (獲取AI深度建議)
8. **批量掃描** (對比多隻股票信號)

## ⚠️ 風險提示

1. 本系統僅供學習參考,不構成投資建議
2. 歷史回測不代表未來收益
3. 投資有風險,入市需謹慎
